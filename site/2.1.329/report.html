旧版で保存した予約タスクの多くは新セッションで再登録が必要。max_tokens 自動リトライ廃止、Code Mode の hook エラー時の扱いも変更。

引数なしはブランチ全体を既定ブランチと比較。PR 指定は gh pr diff で読み、読めなければ黙らず止まる。
