03 注目トピック

BREAKING

ダイアログの y / n が無効に

確定は Enter、取り消しは Esc だけになった。y / n を使い続けたい人は keybindings.json で confirm:yes / confirm:no に割り当て直す。

MAJOR

落ちる・固まる不具合を一掃

毎ターン API エラーで会話が進まない、再開時にクラッシュする、フルスクリーンが強制終了する、といった原因がまとめて塞がれた。

MODEL

Claude Opus 5.5 が登場

既定の Opus モデルになった。1M コンテキスト、料金は入力 $4 / 出力 $20 per Mtok、キャッシュ読み出しは $0.20 per Mtok。
