権限チェックの抜け道を一斉封鎖、/loop も消えなくなった

01 3行でわかる

  • 1Bash の読み取り系コマンドやリンク経由の読み取りで、確認が飛ばされなくなった
  • 2会話の圧縮やバックグラウンド移行の後も、/loop や予約タスクが消えずに動く
  • 3Chrome 連携と添付の無効化は、プロジェクト設定から切り替えられなくなった

02 何が変わる・何が嬉しい

auto モードや sandbox 自動許可でも、意図しない読み取りや実行を防げる。

04 機能の追加・更新・廃止

✨ 新規

attach と logs がセッション名の一部で動く

Managed Agents の構成を自動で用意できる

管理設定が sandbox 許可を無視する時に警告が出る

Slack で !fast と書けば fast モードに

VSCode からマーケットの導入コマンドを確認・実行

🔧 更新

WebSearch 上限が 1 時間 100 回の回復制に

プロキシに弾かれた MCP を無駄に再試行しない

大きなセッションの再開中も入力が止まらない

Chrome の一括操作の待ち時間が 90 秒に延長

VSCode でメッセージ時刻が標準で表示される

🐛 修正

/loop が圧縮・再開・移行の後も正しく発火

WebFetch が 10 万字超の続きを読めるように

画像が大量の長時間セッションで詰まらない

Mac のスリープ復帰で背景エージェントが止まらない

一部のプロキシ経由でリクエストが失敗する問題

rg や git grep の自動承認の抜け道を封鎖

🗑️ 廃止・利用不可

Chrome 連携をプロジェクト設定で ON にできない

添付の無効化をリポジトリ設定で指定できない

pyright と一部の ps は確認なしで動かない

cloud の gh api は他ホストを拒否する

  • pyright を確認なしで動かしていた人 → 必要なら allow ルールに追加する
  • SDK で teammate の agent_id を読む人 → teammate_id を使う
