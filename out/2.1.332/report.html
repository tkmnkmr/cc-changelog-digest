03 注目トピック

BREAKING

クラウドの既定モデル・別名が変更

Foundry は既定が Sonnet 5.5、Bedrock Mantle の sonnet は Sonnet 5 に。未有効化だとエラーになる。

MAJOR

MCP サーバーから Skill が届く（beta）

MCP サーバーが提供する Skill を server:skill の名前で / メニューから呼べる。既存 Skill 名はそのまま。

MODEL

sonnet 別名が Sonnet 5.5 を指すように

Google Cloud と Foundry で sonnet が Sonnet 5.5、Foundry の opus が Opus 5.5 に。Bedrock の sonnet は据え置き。
