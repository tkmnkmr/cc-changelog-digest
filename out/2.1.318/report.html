02 何が変わる・何が嬉しい

03 注目トピック

BREAKING

runner のログ形式が変更

セルフホスト runner の ok/nack 行に reason= が加わり、出力先も変わった。retryable=true: 等に一致させるスクリプトは修正が必要。

MAJOR

ログイン期限の見える化

claude auth status と claude -p の JSON に期限日が載り、10日前から警告。共有ホームでの設定消失対策もまとめて強化。
