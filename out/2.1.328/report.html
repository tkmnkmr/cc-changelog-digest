03 注目トピック

BREAKING

他社クラウドで auto mode が既定に

Bedrock 等の Opus/Sonnet 4.6 は権限モード未指定だと auto mode で起動。Code Mode 出力への UserPromptSubmit hook も廃止。

MAJOR

Code Mode を大幅に磨き込み

0.75秒の待ちを削除、実行中の出力表示、トークン削減。再開時の消失やスクリプト拒否など約20件を修正。
